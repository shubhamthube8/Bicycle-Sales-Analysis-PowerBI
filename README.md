# Bicycle Sales Analysis Dashboard | Power BI
## Project Overview
This project focuses on analyzing bicycle sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profitability, product performance, and geographical sales distribution.
## Dashboard Preview
![Bicycle Sales Dashboard](Bicycle%20Sales%20Dashboard.png)
## Project Objectives
- Analyze overall bicycle sales performance.
- Identify profitable products.
- Compare sales across different countries.
- Analyze monthly units sold.
- Understand yearly sales trends.
- Support data-driven business decisions.
## Dashboard Insights
The dashboard includes the following visualizations:
1. **Sales by Country:** Compares sales performance across different countries.
2. **Units Sold by Month:** Analyzes monthly sales patterns.
3. **Year by Product:** Displays yearly product-related data.
4. **Profit by Product:** Compares profit contributions by product.
5. **Profit by Country:** Visualizes geographical profit distribution.
6. **Sales by Year:** Tracks sales performance over time.
